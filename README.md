# CSS Layout Debugger

This tool provides a visual overlay on a webpage, highlighting the outlines of all elements with randomly generated colors. This can be helpful for:

* Understanding the structure and layout of a webpage
* Identifying potential issues with CSS code
* Debugging CSS and improving front-end development skills

## How it Works

The tool uses a simple JavaScript snippet to:

1. Select all elements on the page using `$$("*")`.
2. Iterate through each element and assign a random color to its `outline` style property.

This effectively creates a colorful overlay on the webpage, making it easier to visualize the layout and identify potential issues.
